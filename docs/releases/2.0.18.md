# HollywoodFX 2.0.18 — Refined Ballistic Impact Sparks

For official SPT 4.1.4 / EFT 0.16.9.5.40743.

## Changes

- Sparks originate at the contact point; reused emitters no longer move or resize older particles.
- Grazing sprays use bounded outward cone sampling instead of flattening inward samples.
- Active shot-family limits survive full tracking storage; backwards clocks cannot refill the budget twice.
- Pellet/fragment accounting charges submitted particles, with cached diagnostic names.
- Restrained realism-oriented defaults retain every existing control and saved configuration.
- No damage, penetration, trajectory, hit-registration or TraumaCore change. The asset bundle is unchanged.

## Verified runtime scope

On September 5, 2026, the maintainer tested `2.0.18-preview.1` in Factory day on official SPT 4.1.4. They approved metal/concrete appearance, then reported that the remaining wood/dirt checks looked good and affirmed automatic-fire behavior without noticeable stutter. This is user-observed behavior, not measured frame-time evidence.

The completed raid recorded 944 spark attempts, 29 emitted events and 85 particles: metal 21 events/72 particles; mineral 8/13; prohibited and unknown surfaces 0/0. There were 361 aggregate material rejections, no invalid/missing particle leaves, no client error entries, a maximum planned impact cap of 14 and maximum frame allowance of 11, below hard bounds of 24 and 96. The surface trace includes 70 wood and 18 soil contacts; counts include AI and secondary contacts, not an aimed-shot tally. Disposal start, summary and completion correlate with the server's raid-end request.

The user then requested release finalization instead of further test rounds. **Not run or not separately confirmed:** second-raid reset, precise shallow-ricochet direction, separated-live-particle testing, complete armor/tracer/ammunition/range/lighting matrix, and Unity frame-time/GC profiling. No claim is made that every original test-matrix row passed. The separately reported headshot-survival concern is not fixed by this visual update.

Finalization does not alter the effect implementation exercised in that raid; release identity and startup wording differ from the preview. Portable validation: 98 checks, including geometry, budget, ownership and defaults. The portable allocation test is not a Unity allocation measurement.

## Install

Close Tarkov. Extract `HollywoodFX-2.0.18.zip` into the SPT root. The archive contains only the DLL and required asset bundle. Existing configuration is not overwritten. New installations receive the new defaults; existing users may choose F12 -> HollywoodFX -> Defaults after preserving custom preferences, then restart.
